# Fiddy Send — WA Bulk Sender Chrome Extension

Send bulk personalized WhatsApp messages from Excel, CSV, or Google Sheets with smart delay pacing and delivery tracking.

**Powered by [Fidean Technologies](https://fideantech.com)**

## Features
- 📊 Import from **Excel (.xlsx/.xls)**, **CSV**, and **VCF** contacts
- 🏷️ Template variables — `{name}`, `{phone}`, `{company}` map to spreadsheet columns
- 🛡️ **Anti-ban safety** — randomized human-like pacing, configurable delays, daily caps
- 🖼️ **Media attachments** — images, documents, brochures
- ✅ **Test mode** — dry run with live message previews before sending
- 🔄 **OTA resilient selectors** — auto-adapts to WhatsApp Web DOM changes
- 📋 **Delivery tracking** — export delivery reports

## Installation
1. Install from [Chrome Web Store](https://chromewebstore.google.com) *(coming soon)*
2. Open WhatsApp Web (`https://web.whatsapp.com`)
3. Click the Fiddy Send icon in your browser toolbar
4. Import your contact list and compose your message
5. Hit Send
